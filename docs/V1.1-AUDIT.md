## Why? help — recommendation

**Yes — expand it.** Mesh/Roaming Why? is the right MilkFlint voice: first sentence on the row, depth + UCI behind **Why?**, optional “recommended” line.

**Rules**

- Only on controls where a wrong choice hurts (offload, VPN DNS, SQM rates, firewall, guest, FT/mesh, WED, country/6 GHz).
- Never decorate every checkbox — that becomes noise.
- Reuse `explain()` + `Field` — do not invent a second pattern.
- Theme already supports `presentation.explanations` (`shown` vs on-request).

**Rollout (landed for this pass)**

1. SQM rates · Tuning (WED/RSS/offload) · Wi‑Fi country / 6 GHz PSC / MU-MIMO  
2. VPN “Use VPN’s DNS” · Firewall hardware flow offload · Guest isolate  
3. DNS / AdGuard / banIP “what this blocks” — next  
4. Advanced-only pages last
