# MilkFlint4 0.6a — Flint 4 / kernel 6.18 debug notes

Compared against OpenWrt main (`github.com/openwrt/openwrt`, mediatek/filogic) and open issues [#26690](https://github.com/openwrt/openwrt/issues/26690) / [#26691](https://github.com/openwrt/openwrt/issues/26691).

## Upstream status (git.openwrt.org / openwrt/openwrt)

- **GL-BE14000 is already in OpenWrt main** (DTS, `filogic.mk`, board.d, panel firmware).
- MilkFlint4 **keeps intentional DTS deltas** that upstream snapshot still lacks for the known RTL8261 bugs:
  - MDIO `clock-frequency = <2500000>`
  - `eee-broken-100tx/1000t/10gt` on the WAN PHY
  - longer `reset-deassert-us` (500 ms)
  - fan active trip **45 °C** (upstream 60 °C)
  - panel reset **ACTIVE_LOW** (Codex P2 / panel bring-up)
- mediatek `patches-6.18` set matches upstream filenames; MilkFlint adds RSS series (`990-*`) + `991-…rtl8261x-retry…`.
- **mt76** in this tree is still **2026-10-08** with a large MilkFlint patch stack; OpenWrt main is **2026-10-28**. Bumping mt76 is deferred (rebase risk on UL MU-MIMO / WED patches).
